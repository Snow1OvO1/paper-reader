# 演示与简历准备

## 五分钟演示

1. 打开平台，指出左侧真实论文与两篇合成材料的区别。
2. 只选《Attention Is All You Need》，提问“论文使用了哪些数据集？”。
3. 展示回答来源 local_model，点击第 7 页引用，核对 WMT 数据集原文与高亮。
4. 查看检索轨迹的 chunk ID、页码和评分，说明评分不是回答正确概率。
5. 只选 Cedar，提问“火星地震震级具体数值是多少？”，演示未找到证据。
6. 选择 Cedar 和 Maple，生成证据对照，查看数据集、指标、方法和局限字段及各自来源。
7. 展开评测报告，对比 keyword、vector、hybrid。解释这只是 10 道合成问题，不代表通用论文准确率。

## 实际发现并修复的问题

**章节标题中的“Limitations”没有随正文入索引。** 初次合成评测在 8 个有答案问题上命中 7 个。正文讲语言限制，却没有重复“limitations”一词，关键词检索漏掉该块。改为索引“章节标题 + 正文”，保留原文内容和原始坐标；加回归用例验证，复测命中全部 8 个。这个结果仅针对同一个小型问题集，存在对测试集调优，不应描述成泛化准确率提升。

**真实论文页首版权说明被当作标题。** 最初取第一个文本块，导致《Attention Is All You Need》显示版权说明。改为结合第一页字号、位置与横向文本范围识别标题，排除竖排边注；这仍是启发式，不保证所有版式正确。

**模型引用不可直接信任。** 引用 ID 不存在、quote 不是原文子串、引用属于另一论文或页码错误，都会被拒绝。模型超时或格式错误退回原文摘录，界面明确显示 source。测试同时覆盖伪造引用和模型不可用。

## 评测解读

- recall_at_5：有答案问题中，预期页码及标注片段是否进入前 5 个检索结果。
- abstention_accuracy：2 个无关问题是否返回未找到证据。
- citation_location_check_rate：有引用的问答中，所有引用是否确实对应候选原文、页码与论文。不是语义蕴含准确率。
- duration_ms：本次执行耗时，不是 P95 延迟，也不是压力测试结果。
- 模型探针仅验证一条实际调用；真实论文文件另记录两个中英文问题，不能据此计算真实问答准确率。

## 如实描述项目

理解并亲自操作代码后，可按实际贡献调整：

> 带证据引用的论文阅读助手｜Python、FastAPI、PyMuPDF、PostgreSQL、pgvector、ONNX Runtime
>
> - 实现 PDF 文本块解析与页码、章节、坐标映射，支持回答引用跳转及原页高亮核对。
> - 结合 BM25 与多语言 E5 向量检索，采用 RRF 融合候选，通过本地模型选择原文证据并校验引用来源。
> - 构建合成问题集和真实论文验证样例，覆盖检索遗漏、跨论文引用、无证据提问和模型失败降级。

这是 AI 辅助完成的项目。不要把 Docker 配置写成已部署容器服务，也不要把小型合成集指标写成真实论文准确率或生产收益。下一步应由你选择日常阅读的论文，独立标注更大问题集，测引用是否充分支持结论。
